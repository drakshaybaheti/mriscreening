# MRI Patient Screening App

A single-page, browser-based MRI screening questionnaire built with HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a modern browser (Chrome, Edge, Firefox, or Safari).

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site; GitHub will show the URL in the Pages settings.

## Important clinical and privacy limitations
- This is a prototype and has not been validated for clinical use.
- A completed questionnaire does not constitute MRI safety clearance. MRI staff must assess positive, uncertain, or unanswered responses under local policy.
- The app does not send data to a server. Do not assume that browser-based use on a shared or managed device is appropriate for identifiable patient data without local privacy review.
- Before clinical deployment, obtain approval from the hospital's MRI safety committee and IT/privacy teams. Add approved secure storage, authentication, audit trails, and device-verification workflows only through a validated implementation.
